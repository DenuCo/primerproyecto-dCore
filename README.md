# dCore

dCore es una plataforma digital diseñada para la difusión y el disfrute de cómics y e-books. Su propósito central es fomentar una experiencia de lectura interactiva, transformando el consumo pasivo de contenido en un espacio de intercambio y colaboración comunitaria.

Este proyecto nació como una práctica de desarrollo Front-End en el programa **Talento Tech** y se encuentra en plena evolución hacia una plataforma **Full Stack**.

## Visión
El núcleo de dCore es la lectura colaborativa. dCore permite a los lectores interactuar directamente sobre las viñetas y párrafos, facilitando debates precisos, notas compartidas y un análisis profundo entre usuarios.

## Tecnologías y Herramientas Utilizadas
El proyecto está construido aplicando fundamentos de desarrollo web:
* **HTML5:** Estructura semántica clara (utilizando `<header>`, `<main>`, `<nav>`, `<footer>` y `<section>`) para organizar el contenido y mejorar la accesibilidad.
* **CSS3:** Maquetado modular y optimizado (principio DRY) combinando **CSS Grid** (para el layout principal) y **Flexbox** (para menús y grillas de contenido).
* **JavaScript:** Manipulación del DOM, gestión de estados locales (`localStorage`) para carritos y favoritos.
* **Control de Versiones:** Git y GitHub implementando un flujo profesional de trabajo basado en ramas.
* **Tipografías e Íconos:** Integración de Google Fonts (*Indie Flower* y *Winky Sans*) y FontAwesome.
* **Formularios:** Integración con Formspree para el envío real de mensajes desde la sección de contacto.

## Estructura Actual
* **Hero / Tendencias:** Sección destacada para la obra principal del momento.
* **Galerías Dinámicas:** Visualización en formato de tarjetas (*cards*) para "Nuevos lanzamientos", "Cómics Populares" y "E-Books Populares".
* **Sistema de Carrito y Favoritos:** Gestión local de obras seleccionadas por el usuario.
* **Navegación:** Menú lateral interactivo y adaptable.

## Roadmap (Próximas Versiones)
dCore está pensado para seguir creciendo. Las próximas etapas de desarrollo técnico comprenden:
- [ ] **Autenticación de Usuarios:** Sistema de login y registro real conectado a una base de datos.
- [ ] **Lectura Colaborativa:** Módulo de comentarios anclados por viñeta o párrafo, permitiendo debates específicos sobre la trama o el arte.
- [ ] **Desarrollo Backend (API REST propia):** Migración de la lógica de almacenamiento local a un servidor robusto con persistencia en base de datos relacional.
